Hotel Reservation System

This is a simple Hotel Reservation System developed in Java as part of the CodeAlpha Java Programming Internship.

The project allows users to view available rooms, book rooms, cancel bookings, and check room details through a console-based application. Different room categories such as Standard, Deluxe, and Suite are included in the system.

Features

- View available rooms
- Book a room
- Cancel a booking
- Room categories (Standard, Deluxe, Suite)
- Payment simulation
- Display room status

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling (if added)

How to Run

1. Download or clone the repository.
2. Open the project in IntelliJ IDEA, Eclipse, or VS Code.
3. Compile and run the Java file.
4. Follow the menu options displayed on the screen.
